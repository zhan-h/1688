采集工具v1.2使用说明
================================

🚀 启动方式：
1. 双击 "商品采集工具.exe" 直接运行

⚠️  注意事项：
1. 确保网络连接正常
2. 采集时请设置合理的间隔时间（程序已自动设置）
3. 建议采集页面不超过50页，避免被限制
4. 初次运行可能被防火墙拦截，请允许访问网络

📝 功能介绍：
- 支持多页采集
- 支持异步请求（1-6）
- 数据可保存为JSON或CSV格式
- 双击表格链接可打开商品页面

🔧 常见问题：
1. 如果程序无法运行，请检查：
   - 是否被杀毒软件拦截
   - 是否有管理员权限
   - 网络连接是否正常

2. 如果采集失败：
   - 可能是IP被临时限制，请稍后再试
   - 减少异步数或采集页数

3. 保存数据失败：
   - 检查保存路径是否有写入权限
   - 尝试保存到桌面或其他位置

如有问题，请查看程序内的日志信息
